# せっかち

せっかちさんがせっかちさんに向けに作成した
メモソフト、さっと出してさっと しまう。

## 概要

ぱっとだして、ぱっとしまうメモ。
せっかちさんは、忙しいんです。ファイル名とかフォルダ構成とか考えててたら、
お腹が空いてしまう。
あの書いたモノ、どこだっけなんて、よくあるけど見つからなければ仕方ない。
探す時間もお腹が空く。

#  実現すべきこと

すぐ書けてすぐ保存できるUI
自動保存やドラフト管理
検索・履歴・タグなどの整理機能はシンプルに

# 開発環境

VScode
C++またはC#
ターゲットOS
必須：Ubuntu
できればば:Windows

#  課題

すぐ書ける。コレを事前に検討する
これによりプラットフォームを決定する。
